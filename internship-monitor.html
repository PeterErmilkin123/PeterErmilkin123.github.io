01 / Personal project · AI-assisted

Accounting Internship
Monitor

An automated project designed to bring structure to an accounting internship search by checking listings, applying search criteria, and tracking opportunities over time.

Focus: Career research & organizationTechnology: Python & GitHub ActionsType: AI-assisted personal project

The problem

Accounting internships are listed across many employer websites and recruiting systems. Rechecking these sources can be repetitive, and it can be difficult to tell whether a listing is new, still open, or relevant to a particular search.

This project brings the search criteria and recurring checks into one workflow.

How the project works

  1. Check career sources. Source adapters retrieve postings from employer career pages and applicant-tracking systems.
  2. Apply matching criteria. Filters review job information for relevant roles, locations, and internship timing.
  3. Keep a record. Saved requisition IDs and listing states help distinguish previously seen opportunities from new matches.
  4. Send notifications. Supported notification services deliver alerts for qualifying openings.

A GitHub Actions workflow schedules recurring runs. The project also includes tests for scheduling, source adapters, multi-location listings, and saved state.

Project context

This is a personal internship-search project developed with AI assistance. Its purpose is to apply technology to a practical research and organization task.

The workflow uses repeatable criteria and a persistent record of listings so each check can build on previous results.

Scope & limitations

The monitor identifies opportunities for the user to review and apply to. Its coverage depends on the availability and structure of external career pages, which can change or block automated requests.

The tool records source failures so unavailable sources can be distinguished from sources with no matching listings.

Project toolkit

  • Python
  • GitHub Actions
  • YAML configuration
  • JSON state tracking
  • Notifications

Why it matters

A concrete example of using technology to make a recurring business-related research task more organized.
